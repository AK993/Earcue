# ADR-012: 字幕卡编辑模式、透明下限、实时预览与文字颜色

## 背景

字幕卡的防泄露设计依赖 `WS_EX_TRANSPARENT`（点击穿透），这带来一个副作用：用户无法用鼠标调整它的位置和大小。同时：

- 透明度最低只能到 20%，不够“隐形”；
- 字体颜色写死为青色，无法匹配不同壁纸/会议软件；
- 外观设置只有保存后才生效，调节时看不到实际效果。

## 决策

### 1. 运行时“调整模式”开关

主界面新增 **🖱 调整** 按钮（再次点击变成 **✅ 完成**）：

- 进入调整模式时，暂时移除 `WS_EX_TRANSPARENT` / `WS_EX_NOACTIVATE`，让浮层可以接收鼠标；
- 卡片显示蓝色虚线边框和右下角缩放手柄；
- **拖动卡片任意位置** → 移动；
- **拖动右下角手柄** → 调整宽度与最小高度；
- 调整结果写回 `config.json`：
  ```json
  "position": "Custom",
  "positionX": 274,
  "positionY": 644,
  "width": 560,
  "minHeight": 214
  ```
- 再次点击“完成”恢复点击穿透；开始采集时自动退出调整模式，避免会议中挡住点击；
- 调整模式不持久化（下次启动默认关闭），避免用户忘记退出后浮层一直拦截鼠标。

高度采用 `MinHeight + SizeToContent`：缩放手柄可以设置一个最小高度，内容更长时卡片仍会继续向上生长，不会把长回答硬裁掉。

### 2. 透明度下限降到 5%

- `overlay.opacity` 的允许范围从 0.2–1.0 改为 **0.05–1.0**；
- 设置页滑块/步进按钮最小值为 5%；
- 调整模式下如果当前透明度过低，会临时提升到至少 45%，保证还能看见边框和手柄；退出后恢复原透明度。

### 3. 实时预览

`SettingsWindow` 新增 `OverlayPreviewChanged` 事件：

- 调节透明度、字号、颜色、位置时，**真实字幕卡**立即应用草稿参数；
- 设置页里的预览卡片同时更新；
- 点击“取消”时恢复打开设置前的浮层外观；
- 点击“保存并应用”时写入配置并保留。

### 4. 答案文字颜色

- 新增 `overlay.answerColor`（默认 `#00F0FF`）；
- 设置页提供 6 个常用色块 + `#RRGGBB` 输入框，支持颜色名；
- 颜色实时应用到字幕卡答案文字和设置页预览；
- 保存时校验格式，非法颜色会提示且不关闭窗口。

## 备选方案

- **始终可拖动**：会破坏点击穿透，会议中遮挡下方应用；改为显式开关。
- **使用系统窗口边框缩放**：`WindowStyle=None` + 透明窗口下原生边框不稳定；用自定义 Thumb 手柄更可控。
- **固定高度缩放**：会裁掉长回答；采用最小高度 + 自动增高。
- **只用设置页静态预览**：用户看不到真实壁纸/位置下的效果；改为双端实时预览。
- **系统颜色对话框**：依赖 WinForms/COM；色块 + Hex 足够覆盖常用场景。

## 后果

- 调整模式下浮层会拦截其区域内的鼠标点击，这是编辑所必需的；调整完请点“完成”。
- 5% 透明度下卡片几乎不可见，但仍在屏幕上；需要编辑时可临时进入调整模式（会自动提升到 45%）。
- 宽度/最小高度会持久化；更换分辨率后如果超出屏幕，`Reposition` 会夹取到工作区内。
- 颜色只影响答案文字；问题行保持灰色，避免喧宾夺主。

- `src/Earcue.Overlay/OverlayManager.cs`：编辑模式与 `LayoutChanged` 事件。

- `src/Earcue.Core/Configuration/EarcueConfig.cs`：`width`、`minHeight`、`answerColor`。
