# ADR-000: 范围与冻结前提

## 状态
已通过 (Accepted)

## 背景
《附耳 Earcue · 项目开发流程》v0.1 已完成立项并明确产品范围与边界。为保证项目在约 6~7 周内高质量交付并避免范围蔓延，制定并冻结 8 条核心前提与范围红线。

## 决策：8 条已冻结前提

| # | 前提 | 说明 |
|---|---|---|
| 1 | 平台 | Windows 10 2004+ / Windows 11，x64 单平台 |
| 2 | 场景 | 线上会议（Teams / 腾讯会议 / 飞书 / Zoom / 钉钉） |
| 3 | 采集 | 系统环回（对方）＋ 麦克风（我方，仅作上下文） |
| 4 | ASR | 本地、流式、中英混说、带标点 |
| 5 | LLM | 云端 API，流式输出 (OpenAI 兼容 SSE 格式) |
| 6 | 呈现 | 置顶半透明字幕卡，仅自己可见，屏幕共享时不可见 |
| 7 | 触发 | 只回答**会议中其他人**提出的问题，不回答自己的提问 |
| 8 | 隐私 | 原始音频不出本机、不落盘；只有文本进入 API |

## 范围红线（明确不做）
- 会议纪要、全文转录、导出
- 对方参会者级的说话人分离
- TTS 代你说话
- 会后回放、知识库沉淀
- 移动端、macOS / Linux
- 团队协作、云端同步

## 发布门槛（v1.0 必须全部满足）
- 端到端首字延迟：P50 ≤ 2.0s / P90 ≤ 3.0s
- 触发精准率：≥ 85%（宁可漏答，不可乱答）
- 触发召回率：≥ 60%
- 稳定性：连续 4 小时会议零崩溃、零断流
- 资源占用：CPU 平均 ≤ 20%，内存 ≤ 1.5 GB
- 隐私：无音频落盘/外传；共享屏幕不可见
- 安装：签名安装包，SmartScreen 无红色警告
