附耳 Earcue v0.1.10 · Windows x64 免安装版

运行
完整解压后双击 Earcue.App.exe。完整版包含 .NET 8 运行时和三套本地 ASR 模型；Lite 轻量版包含运行时，模型可在程序中按需下载。
适用于 Windows 10 2004+ / Windows 11 64 位。
本版本 ZIP：Lite 约 75.3 MiB，三模型完整版约 472.8 MiB。

首次设置
1. 在【设置】中选择模型服务商，填写自己的 API Key，并测试调用。
2. 面试时可在【面试资料】选择角色并填写个人简历。
3. 点击【开始聆听】，系统会监听默认输出设备的声音；音频停顿且识别完成后自动生成回答。
4. 本版本采集系统声音，不采集麦克风。需要我方发言上下文时，请在手动提问中补充。
5. 【调整位置】用于拖动、缩放字幕卡，点击【完成调整】恢复点击穿透。

语音识别模型切换
打开左侧【模型与设置】→【语音识别】，选择模型并点击【保存并应用】。
三套模型：中文流式 Zipformer 14M、中英双语流式 Zipformer、中英双语流式 Paraformer INT8。
已在采集时，先停止采集再重新启动，即使用新模型，无需退出程序。
选择会保存在本机 config.json 中，下次打开程序仍使用该选择。
完整版随包提供 Paraformer CPU 用 INT8 量化权重；Lite 可在设置中下载。

Lite 轻量版与按需下载
打开【模型与设置】→【语音识别】，选择模型后点击【下载所选模型】。
显示下载进度和大小，支持取消；下载完成后校验 SHA256 并安装，保存设置后点击【开始聆听】。
首次开始聆听时若缺少模型，会直接打开语音识别设置，引导选择和下载。
默认下载到 %LOCALAPPDATA%\Earcue\models，可供同一 Windows 用户后续版本复用；已有自定义模型目录时使用该目录。
下载需要访问 GitHub / Hugging Face。取消、网络错误或校验失败时不会将未完成文件作为已安装模型，也不会覆盖已有完整模型。
完整版默认优先使用 INT8 权重，移除了重复的 FP32 权重，三套模型和切换功能保留。

专业词与人名
在【模型与设置】→【语音识别】→【专业词与人名】中每行输入一个词，例如公司名、人名、技术术语或 SQL Server。
最多 200 个词，每个最多 64 字；重复词会合并。保存后停止并重新开始聆听，新的解码词表生效。
两套 Zipformer 会启用束搜索增强能够编码的词：中文 14M 主要增强中文词，双语版还支持英文词组。
解码增强强度范围 0.5～5，默认 1.5；增强会增加 CPU 开销，强度过高可能引起误识别。
当前 Paraformer 不支持解码热词。三套模型的专业词都可作为大模型问题校正的参考，不支持编码的词也会保留供校正参考。
问题校正需开启【自动提取并校正问题】，原始识别文字始终保留，不按词表强行替换。
专业词表保存在本机配置中；生成回答时会随相关文字发送给所选模型服务。不要填入密码或密钥。

根据简历自动填充专业词
先在【面试资料】中填写或导入简历，并保存。
打开【模型与设置】→【语音识别】→【专业词与人名】，点击【根据简历自动填充】。
使用当前回答模型分析已保存的简历；该次请求会把简历文本发送至设置的模型服务，不携带会议对话。
每次最多提取 80 个专业词，优先保留技术栈、编程语言、框架、工具和行业术语；会过滤简历中未出现的词、邮箱、电话号码和网址。
提取结果与现有词表去重合并，保留手工词；超过总计 200 个的部分不会加入，并显示数量。
可点击【取消提取】；取消、超时、格式错误或请求失败时保留原词表，未识别到有效词时也不清空。
结果先填入编辑框，可检查、增删后点击【保存并应用】。停止并重新开始聆听后，新的解码词表生效。
简历为空时会提示先保存资料；简历超过 30,000 字符时请精简后再提取。

新版界面
主界面左侧为导航，右侧分别展示音频状态、本地识别引擎、回答模型、实时转录和回答建议。
【模型与设置】分为回答模型、语音识别、字幕卡、自动应答四个标签。
【面试资料】中左侧选择角色，右侧粘贴或导入简历。
【预览字幕卡】只展示浮层示例，不加入真实回答记录。
回答卡从请求开始即出现在主界面，与字幕卡同步逐步显示内容。
可点击【停止生成】保留已生成部分；【重新回答】再次请求；【复制】复制当前内容，也可选中文字复制。
主动停止生成会暂停自动应答，点击【恢复自动应答】后继续；手动提问和重答仍可使用。
完成的回答分别显示首字等待时间和总生成时间。

字幕卡背景与文字透明度
在【模型与设置】→【字幕卡】中分别调整【背景不透明度】和【文字不透明度】，滑块与加减按钮均可使用。
两项互不影响：0% 完全透明，100% 完全不透明。例如背景设为 0%、文字设为 100%，就只显示文字。
文字设置同时作用于标题、问题、回答和耗时；背景设置作用于底色、边框与背景阴影。
设置页示例和已显示的字幕卡会实时预览；点击【保存并应用】持久保存，点击【取消】恢复原设置。
即使背景和文字都设为 0%，仍可通过【调整位置】显示边框和手柄，或重新进入设置恢复可见度。
旧版整体透明度会自动换算为背景与文字的独立设置，尽量保持升级前的外观。

自动提取与校正问题
默认开启，在【模型与设置】→【自动应答】中可以关闭【自动提取并校正问题】。
自动应答时会合并本轮被 ASR 拆开的转录，提取核心问题或发言要求，并结合上下文整理重复口语、标点和有依据的识别错误。
提取与回答由当前配置的回答大模型在同一次请求中完成，不需要额外下载 ASR 模型；手动输入的问题直接回答。
校正结果直接用于回答，卡片顶部显示整理后的问题，展开【查看识别原文】可核对本轮原始转录。
不确定的词会提示核对；数字、条件、否定和专有名词应保留原意。实际校正质量取决于所配置的模型。
回答完成或停止后，可直接修改卡片顶部的问题，再点击【重新回答】按修改后的问题生成新回答。
未检测到明确提问时保留本轮发言，按原场景继续接话；模型未提供有效校正结果时明确显示保留原文。
整理中也可点击【停止生成】；失败或停止时保留待回答内容，后续新识别的发言不会被旧回答清除。

升级
关闭旧版（托盘右键【彻底退出】），再启动新版。
如需沿用同一电脑、同一 Windows 用户的设置，可在新版启动前将旧目录的 config.json 复制到新目录。
新包默认配置不包含 API Key、个人简历或会议文本。
从完整版配置迁移到 Lite 时，若要使用共享模型缓存，请将 config.json 中的 asr.modelRoot 设为空字符串；保留 models 则会在新版程序目录下载模型。

错误处理
MiMo 官方接口的常规回答会显式关闭默认深度思考，并使用 max_completion_tokens 设置输出上限，以适应实时提取和回答。
流式客户端会识别真实的思考进度，继续等待正文；思考内容不会显示或写入日志。空心跳不算有效进度。
首次有效响应默认等待 15 秒，整次请求默认最多 60 秒；旧版的 5 秒/20 秒默认组合会自动升级，自定义的其他组合保留。
【测试连接】现在使用与正式回答相同的流式客户端和请求参数，分别显示首次正文和总耗时。
日志增加请求模式、输入字数、响应耗时和失败阶段，便于区分首响应超时、总超时和解析错误，不保存请求正文或 Key。
模型鉴权、限流、首字超时和请求超时会明确显示错误。
自动回答、手动提问和重新回答失败后，均会在同一张卡片上持续自动重试，直到成功或主动停止，不限制重试次数。
每次失败后固定等待 2 秒再重试，等待时间不递增；等待期间显示失败原因和重试次数，【停止生成】一直可用。
每次重试会重新生成完整回答，避免将上次的半截内容重复拼接；等待期间保留待回答内容，成功后只确认本次问题，不清除新识别的发言。
点击【停止生成】、停止聆听或彻底退出程序，会同时取消当前请求和后续自动重试。失败等待期间修改模型设置后，下一次重试会使用新配置。
本地识别出错会停止采集并显示提示，已识别文字仍然保留；点击【重新开始】重新加载模型。
音频断开时会尝试重连；重连耗尽后停止采集并显示重启入口。
自动应答同时检查音频能量活动、识别草稿完成状态和停顿时间；持续说话、草稿未完成或音频中断时继续等待。
配置损坏时会保留原文件并尝试创建 config.json.invalid-* 备份，再以默认配置启动。

隐私与界面
音频在本机识别，不保存音频；生成回答时会向所选模型服务发送对话文本及填写的背景资料。
默认日志只记录运行指标，不保存识别出的会议文本；privacy.saveTranscript=true 才会在日志中保存转录。
以前版本已生成的日志不会自动删除，目录为 %LOCALAPPDATA%\Earcue\logs。
API Key 使用 Windows DPAPI 加密；简历以明文保存在本机 config.json，请妥善保管。
字幕卡启用 Windows 捕获排除；实际共享效果应在所用会议软件中确认。
控制台最多保留最近 100 张回答卡片，转录文本采用滚动保留。
关闭主窗口会隐藏到托盘；托盘右键【彻底退出】才会结束程序。
